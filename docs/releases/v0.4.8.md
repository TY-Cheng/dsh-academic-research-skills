# v0.4.8 — Sync vendored ARS to v3.24.5

Syncs the vendored ARS content from the `v3.24.4` pin
(`23807f9`) to upstream release
[v3.24.5](https://github.com/Imbad0202/academic-research-skills/releases/tag/v3.24.5),
commit
`74453f859a4625954e5d2a7dd30c5d716842d060` — 28 upstream commits, a clean
fast-forward.

- 36 vendored files changed (35 modified, 1 added): 200 skill files,
  655 `scripts/`, 155 `shared/`, 4 `agents/`, 4 root files (1,018 total).
  The added file is `scripts/test_tier0_title_gate_prompt_sync.py`; it ships
  with the package so the vendored test layer stays complete.
- Upstream behavior changes now available through the vendored skills:
  `academic-paper` re-checks citations before Phase 7 when a revision round
  changed the citations or reference list (#1071) and its formatter keeps the
  re-check's draft; Tier 0 title search now requires an exact normalized title
  plus the first author's family name, and the OpenAlex/Crossref/arXiv protocol
  docs describe the same rule (#1146, #1148); the literature resolvers treat
  dropped connections and malformed HTTP status lines as API failures (#1181),
  reject identifier hits and skip title searches on null or empty normalized
  titles (#1163, #1166, #1171, #1177, #1180), and Crossref retraction /
  reinstatement notices with unorderable dates now yield `disputed`
  (#1150, #1154, #1170); the `academic-paper` formatter uses parentheses for
  Vancouver and square brackets for IEEE in-text numbers and only allows
  removal of all author information in the blind-review version (#1172);
  `source_verification_agent` can split a claim into premises when the user
  asks (#1128, #1133); the SessionStart announce names the plugin agents'
  current names after a resume or compaction (#1168); the arXiv resolver skips
  citations with no arXiv ID (#1178). These prompt-level changes are
  unmeasured.
- One upstream command source changed (`ars-revision-coach.md`); all 16
  wrappers were regenerated, and only that wrapper's text differs. Claude
  Code-specific instructions are still stripped by the generator.
- Native layer unchanged: `ars-team`, `ars-pipeline-team`, the 5 tools, and the
  registrar counts are the same (23 registrations).
- Upstream's README now names this DSH sibling distribution (#1126). The ARS
  maintainer verified that the vendored skill and core files match the pinned
  commit and reviewed the README and submission documents; the maintainer did
  not audit or run the port's code, and the Claude Code hooks remain unported.
